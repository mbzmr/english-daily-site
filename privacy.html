隐私权政策

更新日期：2026年10月11日。适用于个人自用的 English Daily 本地程序。

访问的信息与用途

程序通过 Google OAuth 请求 Gmail 发送和只读权限。它使用账号邮箱地址核对授权账号，发送本人阅读练习及答案，查询相关练习邮件以防重复，并读取其邮件 ID、标签、收件人、主题和 HTML 正文以确认完整投递。只读权限在 Google 授权层面允许读取邮件；本程序的业务查询用于相关英语练习邮件，不用于处理其他私人邮件。

本地保存

OAuth 访问令牌、刷新令牌和客户端配置保存在用户电脑的本地配置目录，程序限制令牌文件的访问权限。练习、答案、文章来源、审核记录、相关邮件的主题与来源链接，以及投递状态、邮件 ID 和错误记录保存在本地项目中。令牌和客户端密钥不会写入本网站，也不作为内容生成或审核的模型输入。

使用的服务与信息传输

Google 处理授权、邮件发送和查询请求。练习生成与审核通过 Codex CLI 调用用户配置的模型服务；输入包括文章、练习材料、去重所需的练习邮件主题与文章链接。该流程不把 OAuth 令牌、客户端密钥或无关私人邮件正文作为模型输入。模型服务对输入的处理适用该服务及用户所配置账号的政策和设置。

本程序不出售 Google 用户数据，不以邮件数据投放广告。Google API 数据的使用须遵循 Google API 服务用户数据政策，包括 Limited Use 要求。

保留、撤销与删除

本地文件由用户自行控制，当前没有自动删除期限。用户可停用定时任务，在 Google 账号的第三方应用连接设置中撤销授权，并删除本地令牌及项目中的相关记录。删除本地文件不会删除 Gmail 中已发送或接收的邮件；邮件需在 Gmail 中另行管理。

网站与联系

此静态网站没有注册表单、广告、追踪脚本或分析工具；网站托管方可能按其自身政策记录访问日志。政策随程序的数据处理行为变化而更新。如有问题，请联系 liuhaoze404@gmail.com。
